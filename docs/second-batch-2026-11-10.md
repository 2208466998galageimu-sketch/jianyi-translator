# 第二批：免框选 OCR 实施记录

依据已批准的 capture-plan-2026-11-10.md 第 4、6 节继续实施。第一批未提交改动保持原位；本批不改领域知识包与 MT 模型。

1. 同图对照已有 MinerU 与系统 OCR → 验证文字、符号、漏行、双栏、冷/热耗时。
2. 独立可选 OCR 组件、受控截图和光标文字块选择 → 验证离线、取消、禁止读取、列间隔与原文保留。
3. 复用右键菜单、现有热键与浮层，常驻可展开原文校对 → 构建、回归、真实组件协议与界面渲染检查。

影响位置：Core 捕获模型/设置/OCR 行块模型，Capture 截图与本地组件客户端，Storage 设置映射，App 取词路由/右键菜单/浮层，OCR 构建工具、许可证、相关测试与产品/设计文档。截图不默认落盘，RAG 环境只读，发行组件不含 D 盘绝对路径，不自动下载模型，不把拖动两点当真实选区。

当前证据：5 组合成截图已离线对照。MinerU 普通英文与 14px 小字样本逐字正确；代码仍有右花括号、反引号和 O/0 错误，完整代码不可当成可靠可执行源。系统仅安装 zh-Hans-CN OCR，实测其英文网址、数字、符号错误更多；没有安装额外系统语言。选择 MinerU 作为本批唯一推理后端，保留低分行并明确 OCR 原文须校对。双栏必须按光标选择文字块，不能采用引擎全图顺序。

## 已落地与实际使用

- 复用原右键菜单、热键和 310 DIP Popper，不新增一排模式按钮。安装器包含默认不勾选的「本地屏幕 OCR」组件；安装后在右键菜单显式启用。当前窗口内指向文字，按 Ctrl+Shift+D；原文可读时仍用原文，不走截图。
- 无选区只允许主动热键；自动回退须有 UIA 非空选区/行矩形证据并达到 dwell。截图前后检查前台/权限/桌面/遮挡，截图只在有限可见客户区；自身浮窗遮罩，其他应用遮挡则拒绝。GDI 截图不是原子窗口隔离，快速变化场景仍有竞态边界，不能说完全消除误采集风险。
- 按光标种子约束同栏邻行，指向入口最多 16 行；仅识别当前可见块，不恢复屏幕外选区。低分行保留，检测到但识别为空的行显示替代占位并提示；未检测出的行仍可能漏掉，不凭语义补写代码。
- 常驻原文校对区沿用既有 SegItemSmall/GhostButton 样式；悬注只读并提示切常驻可校对。展开原文、修改后可重新翻译。校对控件由用户点击时才激活，不在浮层出现时抢焦点。
- 关闭/Esc/切窗/滚动/选区或焦点变化会取消并丢弃旧结果；自动 OCR 离开选区即取消。修复了冷启动过程中重复 dwell 可能查询空文本、同文从普通取词切 OCR 时原文框为空的问题。常驻面板内滚动不再被全局滚轮误当成源页面滚动关闭。
- 只和本实例隐藏子进程通过内存管道交换 PNG/JSON，无端口；像素/字节/行数/分数/坐标均校验。无截图文件/原文日志，禁用 ORT 遥测与 Python 网络连接；取消/30 秒超时终止本实例进程，空闲 5 分钟释放。剪贴板恢复失败的警告不会被 OCR 成功掩盖。

## 验证结果

- 最终 Release 构建 0 警告、0 错误；全量测试 **121 通过，0 失败，0 跳过**。新增 OCR 路由、负坐标裁剪、双栏/间隔、低分与未识别行保留、协议边界；OCR 设置默认关闭与写读回归通过。
- 从源 MinerU 做 5 图对照，并从清空 PYTHONPATH/PYTHONHOME、限制 PATH 的环境运行冻结 exe；不依赖 RAG 目录启动。非法图片拒绝，下一次合法请求恢复，正常进程 EOF 退出。初次冻结构建曾出现无细节推理失败，重建后未复现；最终组件已重复通过同图/错误恢复检查，未编造初次失败原因。
- 真实 C# 客户端检查 3 行左栏结果无 RIGHT 文字、取消推理后重启恢复；最新一轮首请求 807ms、后续样本 123ms、峰值工作集约 297MiB。此前同机观测 8421ms/1001ms、约 298MiB，组件单独启动观测约 2.1–7.5 秒，最终组件独立验证启动约 2.6 秒。不同轮次波动明显，尚未作系统性能基准，不能把模型热推理的 0.1–0.2 秒当作包含 UIA/截图/浮层的端到端耗时。
- 组件最终约 **242.6 MB / 231.4 MiB**，包括独立运行时与约 22.94 MB 模型。移除了不用的视频解码插件；没有复制整套 venv/PDF/Office/LLM 流水线，没有修改 RAG 环境或下载模型。
- 实际 WPF 资源/浮层渲染与组件自检通过：长文不截断、浮层不激活、OCR 原文可见、校对事件、同文切换原文填充。截图 `artifacts/ocr-qa/overlay-ocr.png`；新控件采用原有分段/按钮样式。
- computer-use 的原生管道报「系统找不到指定的文件」，无法完成真实点击、截图取词和跨窗口验收。没有使用测试结果代替系统验收，也没有弱化前台/密码检查来制造通过。
