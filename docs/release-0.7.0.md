# 简译 0.7.0

本机升级完成于 2026-11-25，源码发布材料整理于 2026-11-26。本记录不是已发布 GitHub Release 的声明。

本轮补齐七语言本地句段翻译、双向和多向包、导入上下文与助手返回重试、四组 OCR 推荐、常驻浮窗调整译法、组合术语首选、独立翻译偏好和请求计数去重。

## 验证

- Release 配置 247 项测试通过。准备的 CI 排除需要交互桌面的 2 条 UIA 用例，运行其余 245 项。
- 真实 WPF/WebView2 设置和语言包流程通过；界面、模型协议夹具与实际模型检查分别记录，不相互替代。
- 七语言 42 个有向组合通过基础运行检查；这不等于语言质量评测通过。
- 打包后的四组 OCR 识别中英文测试图通过；默认组件及精简组件在三组图片各五次运行中的文字、坐标、分数一致。
- 官方 Qwen2.5-1.5B GGUF 通过分句与局部术语调整检查；实际 OCR 导入助手完成未配置、配置后返回修正、试识别后启用的链路。
- 示例提取的小模型质量有限。没有原样示例依据的候选会过滤，最近一次真实检查返回空候选，不宣称偏好推断准确率达标。
- 原目录升级至 0.7.0.0，旧程序和数据有备份；启动后原用户表内容与原三份 OCR 模型哈希核对一致，启动为 ready。
