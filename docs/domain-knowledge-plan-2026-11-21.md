# 领域术语知识库制作计划

日期：2026-11-21。状态：首版已随 0.6.12 安装到本机，等待用户实测 LLM 与桌面交互。

目标：上传智能感知工程等专业领域的术语对照，选定一个或多个库和 LLM 后翻译优先使用命中译法，并能展开查看来源。

1. 数据与导入：新增领域库、术语条目和 SQLite 存储；提供 CSV/TSV 示例与预览，事务确认。验证重启持久化、重复/坏行处理、导入原子性、旧数据保留。
2. 确定性匹配：语言对隔离、完整词边界、长短语优先、禁用过滤、库优先级及冲突。使用真实领域术语样例验证；不自动推断同形词和词形。
3. 独立管理页面：库/条目 CRUD、搜索、导入确认、排序和冲突展示。验证取消不修改、停用即时反映到后续请求。
4. 设置页：快捷选择已有 LLM 模式、显示模型和多选知识库；无有效模型显示配置入口。验证 LocalMt/锁序下不会显示虚假的启用状态。
5. LLM 接入：命中词/短语/句段路由、结构化规则提示、长度限制、请求快照与取消。模拟 HTTP 检查仅发送命中条目、不泄露其他库、不把术语当指令。
6. 结果来源：可展开命中详情，不主动打断；失败与新请求清理旧记录。验证库编辑与并发请求不导致来源错配。
7. 发布：完成针对性回归和实际 LLM/本机模型验证；核对近期 OCR 改进后统一发布。更新本机时备份原安装及数据。

首版不做：通用文档 RAG、PDF/OCR 导入、云同步、自动术语抽取、词频弹窗或普通 MT 的字符串后处理。

验收例：库 A 保存 point cloud→点云、sensor fusion→传感器融合；选中含这两个术语的文本，模型请求带这两项和来源。结果可展开查看；关闭库后下一次请求不带这些术语。cat 不命中 category；重叠术语和多库冲突按已显示的优先级处理。

## 本轮实现情况

- 固定译法完全并入知识库的单条术语管理，不再做独立入口或另一套存储。旧 personal_terms 保留。
- 已实现独立页面、库与条目增删改、搜索、CSV/TSV 预览后加入草稿并保存、同词冲突查看。
- 设置页可切换现有模型模式、多选库；管理页可以启用并设为首选库。设置页顺序即调用优先级。
- 通顺 LLM 模式中，命中专业词/短语会先于通用词典进入 LLM，句段也使用同一套命中规则。锁序和 LocalMt 不调用知识库。
- 只发送命中的术语，最多 100 条及 24000 序列化字符；超限报错，不静默漏用。后台匹配可取消。
- 结果可展开查看本次提供给模型的术语及来源，不能据此保证模型已遵守。新结果和关闭后清理详情。
- 离屏 WPF 已检查真实视图加载、库/表格绑定和搜索。未验证外部模型实际翻译质量，也未替换本机安装版。
- 导入示例见 domain-terms-example.csv。首版的上传指选择本地 CSV/TSV 文件，不会上传整个库。

验证记录：Release 回归 199 项通过；主程序构建及隔离 WPF 页面加载通过。实际模型术语遵循率、跨应用划词及本机安装更新尚未执行。

## 后续升级：按专业领域与词频分级的知识库生成（2026-11-21）

状态：用户提出的后续升级方向，仅记录，当前不实现。与现有资料整理转换分开。

- 知识库生成支持按具体专业领域及该领域词语的出现频率分级；初步分为一级“基础常用”（领域高频）、二级“专业进阶”（领域中频）、三级“细分深入”（领域低频及细分方向）。名称与具体分界在实现前再确认。
- 词频依据应为选定领域的资料语料，保留资料范围和统计口径；通用英语词频不能直接代替领域词频。词频级别表示常见程度，不代表术语难度、重要性或内容可信度，不能简单等同。
- 领域高频专业词可以保留；普通简单词不因出现频繁就收进专业术语库。后续需要制定专业相关性筛选规则。
- 统计时须明确短语、重复文档和词形变体的处理。具体频次、分位数或覆盖率阈值等待领域样本后确定，不预先编造数值。
- 未来可让用户选择领域及所需级别，再生成相应范围的知识库；生成内容与资料中已有条目区分，经过审核后保存。
- 本计划不是按用户查询次数主动提示选择词义，不恢复已取消的词频提醒功能。
