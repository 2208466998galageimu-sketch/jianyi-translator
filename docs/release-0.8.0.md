# 简译 0.8.0 — 使用流程与更多设置调整

日期：2026-11-26。由 0.7.0 开发工作区继续实施，原修改保留在 `ux-0.8-20261126`；源码基线保存在 `backups/before-ux-20261126`。本记录不代表已经公开发布 GitHub Release，也不代表已覆盖本机安装版本。

## 已实现

- 更多设置采用翻译设置、知识库、模型配置、数据与存储四组侧边导航；二级项目按组展开。保留无系统标题栏、圆角、整页拖动与输入控件编辑边界。
- 翻译偏好默认只展示规则、启用开关、添加与保存。示例整理和待确认建议按需展开。关闭主开关停止规则应用及反馈采集；旧场景规则原样保存，可明确转为通用规则，不自动扩大范围。
- LLM 自动语言翻译在同一结构化请求中返回识别的语言，按语言条件提供偏好，并在结果显示实际语言。无法返回有效语言时明确要求手动选择，不默认为英文。中文带句末标点的句子不再归为单个词。
- 控制条增加语言/翻译方式入口和 LLM 知识库组合选择，包含“不使用知识库”；锁序和本地 MT 不启用知识库。
- 常驻结果可复制译文、失败重试、查看使用详情；调整操作下的术语替换和译文编辑按需展开。只读悬注不展示这些按钮。保留框选结果单实例替换和原生命周期规则。
- 模型页面统一当前使用、已有配置与添加方式。本地翻译/LLM 分开，LLM 再区分本机和 API。支持编辑、重新检测、服务商地址预设、兼容接口模型列表及手填。
- 配置存在不再称为实时“已就绪”；分别展示使用中、已安装、已保存、上次检测结果和时间。翻译连接测试覆盖自动语言结构化输出，导入助手测试 JSON 能力。已保存凭据仅返回状态，不回传 Key。
- 移除模型配置默认保留文件；可明确删除简译管理且无其他配置引用的文件。外部/共享模型不提供直接删除。自管 Ollama 模型由其 API 删除，避免直接破坏共享权重。
- 知识库增加库名搜索、词条详情、复选框批量启停/删除、UTF-8 CSV/TSV 导出。批量操作记录版本。词表导出保留方向、备注、来源和启用状态，并提供可逆的表格公式转义标记。
- 组合列表显示成员数量及使用状态；选中编辑、保存、用于翻译分开。新建组合为空，另存组合保留成员；新建不自动启用。继续保留手动/频率排序及显式保存。
- 导入预览可改原词、译法和方向；统计新增、重复、冲突、待核对，支持统一方向和勾选合法条目。相同译法默认跳过；冲突默认保留原有，明确选择更新才覆盖。文件整理和生成继续作为两个任务。
- 标准词表可直接整理至 5000 条、64 MiB 上限；缺语言超过 200 条时不批量调用模型，可在预览统一指定方向。模型生成候选仍有原有独立上限，不随词表上限扩大。
- 版本记录保持弹层，显示新增/修改/删除差异与恢复影响；最多展开前 50 项详情。恢复生成新版本。回收站增加搜索、批量恢复，继续保留组合恢复时选择包含的软删除库、默认全选和彻底删除引用清理。
- 结果显示页保留长度与时长两组设置，显示派生长度范围，可选择秒或分钟输入；恢复默认先改草稿，保存后生效。默认仍为 10/50 和 90/300/600 秒。
- 修改后切换或关闭提供保存、放弃、继续编辑。常规模态表单保存失败保留输入。配置助手后返回导入时保留待处理内容。
- 全局单任务条跨页面显示下载、校验、试运行和启用过程，可取消、重试；下载显示总量和剩余量。
- 下载目录集中管理，默认仍为程序目录下 `data/models`，可选择其他位置。更改后续下载位置和迁移已有模型分开；迁移复制、逐文件核对 SHA-256、成功后更新引用，原文件保留。
- 用户数据备份只含知识库、组合、已确认偏好及基础设置。排除模型文件、连接档案、凭据和本机采集样本。恢复前生成恢复点，检查预览后的版本未变化，并以事务恢复知识库、偏好、基础设置。

## 产物和边界

- 本机安装包：`dist/Jianyi-Setup-0.8.0-compact.exe`，最终大小和 SHA-256 见 `build/ux-0.8-artifacts.json`。
- 发布目录保留 raw/compact 两份，旧 0.7.0 安装包保留。OCR 和本地 MT 宿主复用先前已验证组件，没有重新下载模型。
- 面向真实云服务的连接与翻译质量未在本轮实测；HTTP 兼容性和 JSON 能力通过回环服务验证，不能冒充真实模型质量认证。
- 更改下载位置不自动搬迁旧文件。迁移取消或失败可能保留目标中的未完成副本；原文件和配置在复制校验完成前不变，重试使用空目标文件夹。
- 旧场景规则不会自动改为通用范围；通过规则菜单明确转换。候选采集仍仅覆盖已有三类确定模式，不宣称自动理解全部个人习惯。
- 未实现任意模型权重转换、向量知识库、云端同步、团队权限或自动语义学习；这些不属于本轮确认范围。
- 自有源码许可仍待维护者确认，第三方词典/组件的公开分发边界沿用 `docs/third-party-licensing.md`。本机安装包不自动上传公开平台。

## 实现位置

- `Settings/more-settings.html` 与独立的 `Settings/models.html`：同源离线设置视图，保持页面不能自行联网。
- `MoreSettingsPreferences.cs`、`MoreSettingsModels.cs`、`MoreSettingsData.cs`：偏好、模型及备份/存储操作。
- `TranslationPreferences`、`LlmAlignedTranslation`：按语言应用偏好、自动语言与分句输出检查。
- `UserDataBackup`、`ModelStorage`：备份事务、路径边界与复制校验。
- `OverlayActions`、`OverlayAdjustment`、`PopperWindow`：日常使用操作和渐进展开。
